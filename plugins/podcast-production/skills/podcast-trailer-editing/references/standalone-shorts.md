The generic resource and concatenation helpers remain in this trailer folder for existing callers. Their maintained short-production contracts are also bundled in the separate skill, which can be installed independently. If the separate skill is absent, install its folder from the same editing-skills repository rather than inferring it is available through the account.

Opening-trailer montages and short kinetic-text style pilots remain in this trailer skill.
